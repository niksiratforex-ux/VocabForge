# ⚒️ VocabForge v3.0

**سازنده فلش‌کارت هوشمند برای [Leitner Pro](http://readner.eu.cc/)**

VocabForge ابزاری برای استخراج واژگان انگلیسی از فایل‌های PDF و DOCX (مانند Manhattan 500 GRE)، غنی‌سازی خودکار با تعاریف و مترادف‌ها، ترجمه فارسی، و خروجی JSON مستقیم برای ورود به برنامه مرور لایتنر است.

## 🆕 ویژگی‌های جدید

### 💾 ذخیره‌سازی IndexedDB
- جابجایی از localStorage به IndexedDB — **بدون محدودیت حجم**
- ذخیره ۳۰۰۰+ کارت بدون مشکل
- مهاجرت خودکار داده‌های قبلی

### 🗃️ کش هوشمند غنی‌سازی و ترجمه
- نتایج dictionary و ترجمه در IndexedDB کش می‌شوند
- دفعه بعد فقط کلمات جدید پردازش می‌شوند
- **۲.۵x سریع‌تر** با batch size 20 و تأخیر 50ms
- دکمه پاک کردن کش در صورت نیاز

### 📄 صفحه‌بندی کارت‌ها
- نمایش ۲۰/۳۰/۵۰/۱۰۰ کارت در هر صفحه
- دکمه‌های ناوبری صفحات
- فیلتر و جستجو با ریست خودکار صفحه

### 🎨 بهبود رابط کاربری
- انیمیشن fade-in برای کارت‌ها
- افکت hover روی کارت‌ها و آمار
- نوار پیشرفت شاینی (shimmer)
- آمار غنی‌سازی در بالای صفحه

## ✨ ویژگی‌ها

### 📄 ورود داده
- **DOCX** — پشتیبانی کامل از ساختار Manhattan 500 (جدول ۶ ستونه + سطرهای Example/Context/Note)
- **PDF** — استخراج با محدوده صفحات، حداقل طول کلمه، حداکثر تعداد
- **متن خام** — paste مستقیم متن انگلیسی
- **لیست کلمات** — هر خط یک کلمه

### 🔍 غنی‌سازی خودکار
- **۳ منبع تعریف:**
  - [DictionaryAPI.dev](https://dictionaryapi.dev/) — تلفظ، POS، مترادف، متضاد
  - [Wiktionary REST API](https://en.wiktionary.org/) — پوشش گسترده لغات GRE/SAT
  - [Datamuse API](https://www.datamuse.com/) — روابط واژگانی
- **هوشمند:** تبدیل خودکار فرم‌های مشتق (`-ing`, `-ed`, `-tion`, `-ment`, `-ly`, ...)
- **پردازش موازی:** ۲۰ درخواست همزمان برای سرعت بالا
- **کش IndexedDB:** نتایج ذخیره می‌شوند، دوباره API زده نمی‌شود

### 🌐 ترجمه فارسی
- **ترجمه بر اساس معنی انگلیسی** (نه کلمه به کلمه)
- **۲ منبع ترجمه:**
  - MyMemory API (اولویت اول)
  - Google Translate unofficial (fallback خودکار)
- **پردازش موازی:** ۲۰ درخواست همزمان
- **کش IndexedDB:** ترجمه‌ها ذخیره می‌شوند

### 🃏 مدیریت کارت‌ها
- نمایش با فیلتر (کامل / ناقص / ترجمه‌شده)
- **صفحه‌بندی** با انتخاب تعداد (۲۰/۳۰/۵۰/۱۰۰/همه)
- ویرایش هر فیلد (ترجمه، تعریف، مثال، مترادف، متضاد، یادداشت، نکته مهم)
- تلفظ 🔊

### 💾 خروجی لایتنر
- JSON با فرمت دقیق `importStateSnapshot`
- شامل تمام فیلدها: definitions, examples, synonyms, antonyms, coreMeaning, collocations, note, trap, FSRS fields
- مستقیماً در لایتنر بخش «بازیابی از پشتیبان» وارد کنید
- **سازگار با ورود با انتخاب و مقصد** در لایتنر ۳.۸.۳

## 🚀 نحوه استفاده

1. فایل `vocabforge.html` را در مرورگر باز کنید
2. از بخش **ورود داده**، فایل DOCX/PDF خود را انتخاب کنید
3. دکمه **🔍 استخراج** را بزنید
4. به بخش **غنی‌سازی** بروید و **🔍 غنی‌سازی** را بزنید
5. **🌐 ترجمه** را بزنید
6. از بخش **خروجی لایتنر** فایل JSON را دانلود کنید
7. در برنامه لایتنر → بخش ورود → فایل JSON را انتخاب کنید → کلمات را انتخاب و مقصد را مشخص کنید

## 📊 API‌های استفاده‌شده

| API | منبع | محدودیت |
|-----|-------|---------|
| DictionaryAPI.dev | تعریف، تلفظ، مترادف | رایگان، بدون محدودیت |
| Wiktionary REST | تعریف لغات نادر | رایگان، بدون محدودیت |

## 🔗 ارتباط با لایتنر

VocabForge خروجی JSON تولید می‌کند که مستقیماً با تابع `importStateSnapshot` در لایتنر Pro سازگار است. در نسخه ۳.۸.۳ لایتنر، ورود فایل JSON به صورت **انتخابی** انجام می‌شود — می‌توانید کلمات را انتخاب کنید و مقصد (کتابخانه یا حافظه بلندمدت) را مشخص کنید.
